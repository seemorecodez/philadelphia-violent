# Audio source candidates

See `../../AUDIO-SOURCES.md` for source/license, runtime selection and limitations.

- `01-footstep.ogg` through `04-footstep.ogg`: original CC0 recordings by
  GboxMikeFozzy, https://opengameart.org/content/footsteps-0.
- `01-footstep.wav`, `02-footstep.wav`: temporary mono 16 kHz decoding checks.
- `enginehum3.ogg`: original **Engine Sound** by kurt,
  https://opengameart.org/content/engine-sound, licensed CC BY 3.0,
  https://creativecommons.org/licenses/by/3.0/.
- `enginehum3.wav`: six-second mono 16 kHz excerpt converted from that recording.

The engine candidate is not included in runtime. The current tools explicitly
reject audio input, so none of these files received a claimed listening review.
