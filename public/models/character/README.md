# Walking character

Original [Cesium Man](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CesiumMan), by Cesium, CC BY 4.0. Retrieved September 11, 2026.

Authored mesh, skinning and animation preserved. The original logo-bearing texture is not displayed; a plain neutral material replaces it. Root scale 1.195 makes the rest-pose height about 1.8 metres. This is a neutral starting character; customization is not implemented.
